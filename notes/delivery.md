## Как обновить версию для команды

1. `npm run build` — пересобирает `wordblocks.html` и `docs/index.html` из исходников.
2. Коммит и пуш в main. Из Claude Code это делается прямо в сессии; без оболочки —
   двойной клик по `git-push.bat`, он спросит текст коммита и отправит на GitHub.

Через минуту GitHub Pages подхватывает новую версию по тому же адресу. Коллегам стоит
обновить страницу: браузер охотно держит старую копию в кеше.

Для обновления артефакта в Claude нужна ещё сборка варианта публикации:
`npm run build -- --artifact` и повторная публикация `dist/artifact.html` по тому же
адресу. Публиковать артефакт умеет только сессия Claude с этим инструментом;
из Claude Code обновляется страница на GitHub Pages, и этого достаточно.

## Устройство раздачи

Игра — один самодостаточный html: код, словарь и стили внутри, внешних запросов нет.
В репозитории он лежит дважды: `wordblocks.html` для запуска с диска и `docs/index.html`
под именем, которое раздаёт GitHub Pages из папки `/docs`. Оба файла делает одна команда
сборки, так что разойтись они не могут.

Гит на машине настроен по HTTPS с менеджером учётных данных Windows, без SSH-ключей.
Поэтому пуш работает у того, кто запускает команды на самой Windows: у Claude Code
в этой папке или у человека через `git-init.bat` и `git-push.bat`. Облачная сессия
Cowork команды здесь не выполняет вовсе — она только записывает файлы.

## Ограничение, о котором стоит помнить

Прогресс уровней хранится в localStorage браузера каждого игрока отдельно: у тебя локально
свой, на опубликованной странице свой, у каждого коллеги свой. Увидеть, кто докуда дошёл
и где массово застревают, так нельзя — для этого нужен сбор статистики на сервер.
